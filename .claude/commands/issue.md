GitHub 이슈를 생성해줘.

## 작업 순서

1. `.github/ISSUE_TEMPLATE/feature.md` 템플릿을 읽고 구조 확인
2. 이슈의 목적과 내용을 파악하여 템플릿 형식에 맞춰 작성
3. 작성한 이슈 내용을 나에게 먼저 보여주고 승인받기
4. `gh issue create`로 이슈 생성

## 주의사항

- Assignee는 나(이슈 작성자)로 설정
- 타입에 맞는 라벨 추가 (feat, fix, refactor, docs 등)
- 제목은 "타입: 간결한 설명" 형식
- 작업 내용은 구체적이고 명확하게 작성
- 체크리스트는 실제 추적 가능한 항목으로 구성
